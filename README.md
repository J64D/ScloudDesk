# ScloudDesk

> **Suporte de TI sem ruído: chamados, prioridades e pessoas no mesmo lugar.**

O ScloudDesk é um protótipo de central de atendimento de TI desenvolvido por **J64D** para portfólio. A interface organiza chamados por status e prioridade e apresenta uma visão rápida da operação e da equipe de suporte.

## Funcionalidades demonstrativas

- Painel de visão geral e central de chamados.
- Criação de chamados com categoria, departamento, prioridade e descrição.
- Busca por chamado, título, solicitante ou departamento.
- Filtros por status e prioridade, paginação e ordenação.
- Atualização do status e visualização dos detalhes de um chamado.
- Exportação dos chamados filtrados para CSV.
- Tema claro/escuro e navegação adaptada para telas menores.
- Visão demonstrativa da equipe e de indicadores operacionais.

## Tecnologias

- React 18 e TypeScript
- Vite
- Lucide React
- CSS

## Executar localmente

Requisitos: Node.js e npm.

Na pasta `ScloudDesk`:

```powershell
npm install
npm run dev
```

Abra o endereço exibido pelo Vite, normalmente `http://localhost:5173`.

## Scripts

```powershell
npm run dev
npm run build
npm run preview
```

## Escopo do protótipo

O projeto é uma demonstração de frontend: não possui API nem banco de dados. Chamados e alterações ficam apenas no estado da página e são perdidos ao recarregar. Os nomes, números e registros exibidos são dados fictícios para demonstração; não representam uma operação real.
